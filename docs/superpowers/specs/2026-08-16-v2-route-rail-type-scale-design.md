# 《北境回响》V2 路线左栏字号与地图卡片调整

## 目标

根据浏览器批注，提高路线页左栏的信息可读性，并缩短地图底部当前点位卡。调整只影响路线页视觉，不修改点位顺序、地图逻辑、导览流程或文案。

## 左栏

- 常规桌面端左栏由 360px 调整到 390px，宽屏调整到 410px；1180px 以下仍保持 350px，避免地图空间过窄。
- 路线标题使用 `clamp()` 在 34px 至 40px 之间自适应；简介、进度文字同步提高一级。
- 每个站点格子保持五等分。站名提高到 18px，说明提高到 14px，状态提高到 13px，编号提高到 21px。
- 站点文字组增加纵向间距，使名称和说明在视觉上占据卡片高度的一半左右，同时保留长俄语名称的两行空间。

## 地图当前点位卡

- 卡片从左右贯穿改为左下角紧凑宽度，宽度与左栏接近，使用 `clamp(360px, 34vw, 470px)`。
- 卡片仍保留编号、当前点位、名称、说明和进入按钮；不改变点击行为。
- 小于 900px 的桌面兜底下恢复左右固定边距，避免卡片与地图工具冲突。

## 验收

- 1435×987 下五个站点和“进入导览”按钮完整可见。
- 1366×768 下左栏无横向溢出，必要时允许左栏自身纵向滚动。
- 中俄双语下站名不被状态文字遮挡。
- 地图当前点位卡不再横跨地图，且不遮挡主要点位区域。
- `npm run validate` 全部通过。
