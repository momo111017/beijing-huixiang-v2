# V2 导览探索区上下布局设计

## 目标

将点位导览页右侧的“站点任务”与“继续追问”从左右两栏改为上下两块全宽布局，改善俄文内容过小和卡片底部留白过多的问题。

## 布局决策

- 站点任务位于上方，占满内容区宽度。
- 三个任务选项在桌面端横向排列，以利用增加的宽度并压缩垂直高度。
- 继续追问位于下方，占满内容区宽度；问题按钮纵向排列，避免俄文句子被过度压缩。
- 两块卡片按实际内容收高，不使用等高拉伸。
- “完成本章并前往下一站”保持在右侧底部，始终可见、可点击。
- 保持右侧整体无滚动；只有追问答案在极端长文本时允许内部滚动。

## 尺寸与验收

- 在 1366×768、1440×900 和 1920×1080 下检查。
- 任务和追问按钮的最小高度提升至 34px，字号不低于 11px。
- 两块卡片不重叠，探索区不溢出，页面不产生水平滚动。
- 底部下一站按钮在三种桌面端尺寸下都完整可见。
