# V3 俄语用户反馈修复设计

**日期：** 2026-08-18  
**基线：** V2 提交 `5ea9391`  
**范围：** 根据《V2 对比反馈报告 俄语用户》修复俄语内容、音频文稿、站点信息结构、任务问答和桌面端地图加载问题。

## 目标

V3 让俄语用户在五站路线中获得内容不重复、历史信息足够、音频与文字一致的导览体验，并保证百度地图加载失败时仍能从点位列表继续使用路线。移动端视觉适配、真实后台、账号同步和交通导航不在本轮范围内。

## 设计决策

### 1. 内容分层

每个点位保持四层内容边界：

- **站点简介：** 地点、时代和路线位置的快速理解。
- **场景讲解：** 页面内的连续历史叙事，补充背景和时间线。
- **音频导览：** 与文字稿逐段对应的现场听觉版本，不再承担完全不同的事实。
- **任务与史料追问：** 任务偏现场观察或历史判断，追问偏来源材料中的补充事实。

修改后的内容继续使用现有 `bilingual()`、`sourceIds`、`questionIds` 和 `audio.transcript` 数据模型，不新增开放域 AI。

### 2. 音频审核状态

先更新五份俄语文字稿和界面文案，再由俄语成员核听并替换 MP3。未完成母语核听的音频继续保持 `needs-review`，不能被发布校验误标为正式内容。V3 验收记录应分别记录“文字稿已改”和“录音已复核”。

### 3. 地图加载兜底

保留百度地图作为增强能力，但地图失败时在首页和路线页显示可操作的五站列表，而不是只显示错误状态。加载器增加明确的失败原因和可重试状态；地图成功后继续使用现有标记、列表和点位卡联动。此修复只验证桌面端行为，不扩展移动端布局。

### 4. 反馈中的重点内容

- 更新路线说明、五站标题、首页介绍、打开导览和音频状态文案。
- 扩充秋林公司、圣索菲亚大教堂、斯大林公园的俄语讲解；哈尔滨站和纪念碑同步做重复度和信息密度检查。
- 让站点任务和史料追问不再复述音频原句，并为新增答案保留来源。
- 修正音频文字稿与 MP3 可能不一致的提示与校验。

## 非目标

- 不做移动端适配或重新设计响应式断点。
- 不建设内容管理后台、账号系统、云端进度和开放域 AI。
- 不实现步行、公交、地铁、打车或实时导航。

## 验收标准

1. `npm run validate` 通过，现有测试不回退。
2. 俄语文案回归测试覆盖反馈中指定的关键短语和按钮。
3. 五站文字稿均存在、非空、与点位音频路径对应；待复核状态明确可见于发布校验。
4. 五站每个点位至少有两条来源追问，且问题答案不直接复制场景正文。
5. 百度地图加载失败时，首页和路线页仍显示五站列表，重试按钮可再次初始化地图。
6. 桌面端实机检查确认地图成功、失败、重试三种状态均不阻断路线进入导览。
