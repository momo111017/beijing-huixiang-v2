# V2 桌面端全局 UI 柔化与路线页可读性设计

## 背景与目标

当前 V2 使用大量 9—11px 的界面文字，全局圆角令牌仅为 4px，路线页左栏又受 340px 宽度和紧凑点位卡片限制，导致桌面端观感偏硬、字号偏小，五个点位与页面垂直空间的利用也不均衡。

本轮目标是在不改动信息架构、地图逻辑和内容数据的前提下，提升全站电脑端可读性，让“我的路线”左栏真正填满可用空间，并用节制的圆角与阴影柔化视觉。

## 方向选择

可选方向包括：

1. 局部修补：只改路线页左栏字号和点位高度。风险最低，但首页、地图浮层和导览页仍会保留大量过小文字和硬边框。
2. 中等柔化（采用）：建立稳定的字号下限和 8—12px 圆角层级，并重新分配路线左栏空间。能解决问题，同时保留历史档案感。
3. 大幅卡片化：所有内容改为大圆角浮层与明显阴影。视觉轻松，但容易成为通用模板风，不符合“少用 AI 味”的方向。

## 视觉系统

### 圆角

- 全局基础圆角由 4px 提升为 10px。
- 小按钮、章节切换、状态标签使用 8px。
- 点位卡、导览任务、追问、资料卡和地图浮层使用 10—12px。
- 不使用胶囊式大圆角，不改动现有环形站点编号。

### 字号

- 主导航、按钮、点位状态与说明文字不低于 12px。
- 地图标题、来源标注、照片版权等次要元数据不低于 10px。
- 路线左栏站名使用 15—16px，角色说明与状态均不低于 12px。
- 正文维持 13—15px，俄文长句优先通过行高和可用宽度提升可读性，不用压缩字号换空间。

### 边框与阴影

- 保留纸张米白、松绿与锈红配色。
- 静态内容卡主要使用浅边框和底色分区；阴影只用于地图覆盖层、浮层和当前激活卡。统一使用一个低强度阴影令牌，不在整页堆叠悬浮卡片。
- 激活状态仍使用松绿底和锈红辅助色，不引入渐变、发光或高饱和新颜色。

## 我的路线页

- 左栏在宽度不低于 1600px 时使用 380px，在 1181—1599px 时使用 360px，在 821—1180px 时使用 340px。1366px 和 1440px 验收尺寸因此使用 360px，1920px 使用 380px。
- 减少左栏上下无效留白，使用“标题区＋进度区＋五站等分区＋主按钮”的固定层级。
- 五个点位卡用 `repeat(5, minmax(68px, 1fr))` 类似策略均匀填满剩余高度，卡片间距提升至 8—10px。
- 点位卡增加 12—14px 内边距、圆角和悬停反馈；当前站使用深绿底、浅色文字和轻微投影。
- 底部“进入导览”按钮保持全宽，高度 50—52px，不与点位卡重叠。
- 右侧地图保持满屏，工具按钮和底部当前点位卡改为与全站一致的圆角与字号。

## 其他页面的全局调整

- 首页：放大事实栏说明、地图标题和地图点位卡次要文字；按钮和地图卡使用中等圆角。
- 点位导览：任务、追问、场景切换、答案区和底部下一站按钮统一圆角；小字提升后仍要保证 1366×768 一屏可见。
- 史料来源：卡片和筛选按钮统一圆角，元数据从 8—10px 提升至 10—12px。
- 顶部导航：不改栏目数量和位置，只放大辅助按钮文字并柔化外框。

## 限制

- 本轮仅以电脑端为正式验收对象，不重做手机端。
- 不更换字体家族、配色、照片或地图服务。
- 不新增动画库、组件库或外部依赖。
- 不改动中俄文本、路线顺序、任务和问答逻辑。
- 不部署 V2，不覆盖 V1。

## 验收标准

- 1366×768、1440×900、1920×1080 下路线页无水平溢出，五个点位卡和底部主按钮同屏完整可见。
- 路线左栏五个点位卡填满标题、进度和底部按钮之间的可用高度，无大段空白。
- 主要可见界面文字不低于 12px；仅元数据、版权和来源类文字可使用 10—11px。
- 首页、路线页、点位导览和史料来源页的按钮、卡片和浮层圆角层级一致。
- 静态内容区不出现大面积悬浮卡片堆叠或明显模板化阴影；低强度阴影只出现在地图覆盖层、浮层和激活状态。
- 点位导览在放大小字后仍保持一屏、无遮挡，下一站按钮仍可用。
- `npm run validate` 通过，浏览器控制台无本项相关错误或警告。
